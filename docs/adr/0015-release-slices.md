# ADR-0015: Release slices replace one oversized MVP label

## Context
The master specification's nineteen milestones exceed what users normally understand as one MVP.

## Decision
Track Technical Preview (M0–M2), Agent-native Alpha (M3–M6), Engine Beta (M7–M14) and complete MVP/0.1 (M15–M19), without removing master-spec acceptance requirements.

## Alternatives
One long invisible MVP phase was rejected.

## Consequences
Each slice is demonstrable, benchmarked and releasable while preserving the long-term definition of done.

## Status
Accepted.
