# P2 — consuming shared services

Review candidate over accepted P1. Engine reexports GitHub transport/native picker/Documents from a publicly pinned HTTPS Platform package with lockfile integrity. No permanent copied source or local checkout link. Hosted account credential lives in Platform memory and service IPC is bound to session; native startup owns its own session using the same transport.

Destinations/preferences/history/journal/publication/bundle validation remain per Engine project outside user source documents. Adopt legacy native settings only for matching identity. Close one hosted editor without disconnecting others; disconnect changes account epoch and invalidates old requests/reviews. In-flight publication can be uncertain and needs reconciliation, not blind retry or promised remote rollback.

Import/list are product capabilities; Platform grants bounded source reads/copy and broker import is read-only. Source files stay intact. Duplicate identity reuses/rejects existing catalog entry; changing storage moves no documents. P2 uses controlled account/picker evidence, not real PAT/manual selection acceptance.
