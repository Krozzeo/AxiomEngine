# Reproducing the M19 audit

Normal Engine checks use only committed normalized interface facts. They require no Unity installation, account, network reference download or vendor DLL. `node --test tests/compatibility.test.mjs` validates manifests, hashes, IDs, assignment, SDK source hashes, inheritance/accessor policy and bounded API queries. `python -m unittest discover -s scripts/compatibility -p test_inventory.py` tests parser fixtures. Run the real runtime/UI corpus with `npm run test:browser:m19` after the normal build/compiler/browser setup.

## Baseline regeneration (explicit audit operation)

Keep raw references in a separate cache **outside this repository**. Do not ship them. Preserve all source hashes from `docs/compatibility/*snapshot.json`, including metadata provenance; mutable documentation URLs cannot replace this frozen capture silently.

1. Obtain the official6000.3 offline documentation archive at the manifest URL and verify archive SHA256. Obtain the pinned UnityCsReference commit/ZIP recorded in `snapshot.json.referenceSource`; use it only as declaration metadata. No implementation/example/prose is copied.
2. Obtain official Windows editor6000.3.27f1 and Android/iOS support archives listed under `native-snapshot.json.binarySources`. Verify both recorded publisher integrity and SHA256 before extracting managed assemblies into a cache. Never execute/install the archives to run this extractor. Extraction is external tooling, not an Engine runtime dependency; NSISBI solid archives require a compatible archive reader. Canonical source-relative directory names are recorded in the manifest. Preserve assembly hashes/MVIDs and the selected profile.
3. `dotnet run --project scripts/compatibility/Metadata -- <managed-cache> <native-facts.json> docs/compatibility/reference-requests.json` reads PE metadata with `System.Reflection.Metadata`, without `Assembly.Load` or vendor method-body decoding. Default selection is Windows editor Managed plus Android/iOS editor extensions; duplicated player variants are excluded. Requested non-public owners are retained only to classify published entries accurately.
4. `dotnet run --project scripts/compatibility/Surface -- <Engine-root> > <sdk-surface.json>` parses own explicit public C# syntax. `--reference` and `--missing <requests.json>` parse cached reference types and requested declarations. Combine reference-member and native-fact JSON arrays outside Git as the supplementation input. No body, initializer implementation or source comments are retained.
5. Run `python scripts/compatibility/inventory.py <UnityDocumentation.zip> --reference-types <reference-types.json> --reference-members <combined-facts.json> --reference-source <reference-source.json>`; then `map_surface.py <sdk-surface.json>` and `native.py <native-facts.json> <binary-manifests-directory> <sdk-surface.json>`. Output gzip timestamps are zero and IDs/hashes deterministic. Frozen baseline files must not be edited by a runtime update.
6. `packages.py <UnityDocumentation.zip> <external-package-cache>` records frozen manual recommendations and hashed public DocFX xref maps. This command may download missing maps. Minor-version docs do not prove binary patch equivalence; unavailable versions/indexes remain blocked, with no credit.
7. `relations.py <unity-6.6-toc.js>` generates inheritance, scope weighting and the separately hashed type-only delta. Review every baseline diff and preserve exclusions/blocked records. Rerun validators and the editable corpus.

The PE and Roslyn tools target the repository's.NET10 SDK, use SDK/runtime libraries and have no extra NuGet dependency. Compiled bin/obj, Python cache, raw references, archives and vendor assemblies are ignored/external and must never enter a release. Baseline regeneration is separate from runtime API implementation and does not increase coverage.
