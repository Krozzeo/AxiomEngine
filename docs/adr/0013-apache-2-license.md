# ADR-0013: Apache License 2.0

## Context
Axiom needs permissive commercial and open-source adoption with an explicit patent grant.

## Decision
License the project under Apache-2.0.

## Alternatives
MIT, dual MIT/Apache-2.0 and copyleft licenses were considered.

## Consequences
Distributions retain the license and notices; dependencies require compatible license review.

## Status
Accepted.
