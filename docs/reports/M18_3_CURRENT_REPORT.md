More info has a copy icon before the request navigation arrows.

AI receives a compact index and selected section reads; targeted upserts preserve unrelated sections. PMD tools cannot edit game scene/scripts or approve their own decisions. Imports support UTF-8 TXT/MD/JSON, DOCX text, selectable PDF text and round-trip ZIP; no OCR or fidelity claim for layout/tables/images. Limits: 64 sections, 32 KiB section data, 40 chat messages, six history snapshots, bounded project document storage. AI Master remains planned.

Project prefab capture/instantiation preserves subtree/components, remaps internal references and blocks dangling external entity references. Linked instances are blue; originals are locked except root placement and script value overrides. Added children remain editable. Desassemble detaches, Undo restores. Box proxy collision, silent audio placeholder and no automatic orbit occlusion are explicit limits. Existing linked instances do not automatically receive prefab file edits.
