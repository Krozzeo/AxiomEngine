How to run the editable corpus

Create the M19 Compatibility Observatory demo using npm run demo:m19, open it from the Hub and press Play. Edit Scripts/CompatibilityProbe.cs in the IDE and recompile. The probe reports positive, negative and lifecycle checks. It does not implement pending Unity APIs or replace a Unity 6.3 comparison run.
