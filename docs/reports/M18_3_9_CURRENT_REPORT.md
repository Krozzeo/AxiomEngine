# M18.3.9 / 0.0.47 — Input, scenes/resources and physics extension

Status: implementation complete; cross-platform acceptance in progress. Draft PR #38 remains open and unmerged. Do not treat earlier run results as final acceptance.

## Behavior

- Live Hierarchy and selection use runtime entities, detect topology/name/parent changes, clear destroyed handles and preserve the authored document. Root clones use exact suffix ` (clone)`; descendants retain names. Nonrendered entities receive clickable Scene markers.
- SDK 6 includes keyboard/mouse/gamepad/touch snapshots, buffered short press edges, bounded named button/axis rebinding, binding serialization and project-specific PlayerPrefs.
- Physical scene and prefab JSON resources provide Single/Additive scene load/unload, root ownership, scene moves, persistent roots and prefab instantiation; TextAsset and blueprint lookups are bounded. Imported entity references are remapped. Scene assets share current project resources and compiled scripts.
- Native Rust adds gravity vectors, damping, moving kinematic bodies, per-axis constraints, explicit sleep/wake/impact wake, collision exclusions, bounded continuous substeps and pre-solver point velocity/normal impulse evidence. SDK adds static/simulated 2D bodies, shape casts and limited ContactFilter2D.
- Five marked demos are generated by the main demo command. No player-demo repeat is required.

## Validation targets

Rust native tests and Wasm host acceptance; Node atomic packet/persistence/device/resource tests; real C# development/AOT on Linux and development on Windows; browser clone selection and live input/scene/resource/persistence flows. Tests use controlled input devices, not a claim of validation on every physical controller/touchscreen. No paid model requests.

## Explicit limits

See [BATCHES.md](../scripting-api/BATCHES.md). The six expanded batches are not complete Unity compatibility. Advanced shapes/joints/compound physics, automatic sleeping/interpolation, analytic/angular CCD, streaming/Addressables/general save files, Unity Input System/haptics/sensors remain pending. Scene loads consume a lifetime Play creation budget; Async load means already resident data, not background streaming. PlayerPrefs is browser/origin/project storage, not portable project content.

Remaining main SDK batches: presentation; navigation/networking; platform/tooling. Original weighted MVP coverage remains approximately 94% (122/130); expanded SDK scope is not separately weighted. M18.4 GitHub integration and M19 hardening remain roadmap items.
