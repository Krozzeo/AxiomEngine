# JsonUtility

Serialize public primitive fields and Vector2/Vector3 with ToJson, FromJson<T> and FromJsonOverwrite. Compiled generic type roots preserve public fields for AOT. Nested classes, lists, polymorphism, dictionaries and private serialized fields are not supported and throw. Use PlayerPrefs.SetString/Save to persist the returned JSON. Example: var json = JsonUtility.ToJson(new SaveData()); var data = JsonUtility.FromJson<SaveData>(json);
