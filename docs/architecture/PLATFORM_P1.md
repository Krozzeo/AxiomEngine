# P1 — Game Engine lifecycle adapter

Historical first integration, subsequently accepted and merged. Product manifest/protocol1/API0.1, native format1 and SDK 8 unchanged. Adapter lives here; Platform never imports Engine internals. Hosted create/open/status/save/close use a transactional authoring port and independent authenticated editor. Folder leases and sequenced buffer reports prevent concurrent ownership/stale clean reports. Save/close check revisions/idle state; pending code buffers must be saved in editor or explicitly discarded. Hosted Hub cannot switch the host-owned project. Direct startup remains after lease release.

Current execution and acceptance use [P4 guide](PLATFORM_P4.md). [Historical report](../reports/PLATFORM_P1_REPORT.md) retains original tests/results; complete original source is archived as text. P1 did not extract GitHub/AI/catalog persistence or add a game exporter. Forced shutdown requires owner inspection/backup before stale-lock recovery; older pre-lease binaries must not share folders concurrently.
